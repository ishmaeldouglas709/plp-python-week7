# Week 7 Assignment: Python Notes and Report Builder

- `my_notes.py`: Writes three notes to a file, appends a fourth, reads the file back, and counts the lines.
- `my_notes.txt`: The notes file generated by `my_notes.py`.
- `report_builder.py`: Reads `hubs.csv`, calculates pass/fail counts and the average score, and writes `report.txt`.
- `hubs.csv`: The learner data (name, hub, score) that `report_builder.py` reads.
- `report.txt`: The summary report generated by `report_builder.py`.

If `"a"` were changed to `"w"` in the second block of `my_notes.py`, the file would be erased and overwritten with only "I added this later" each time the program runs. The file would then contain 1 line instead of 4, and the first three notes would be lost.
